### 概要
- 開発環境が動作しない状況になっているので立て直したい
- フォルダ構成を以下のように整理して動作するようにしたい

### フォルダ構成
- root
  +- backend    バックエンド関連、serverの下にコードがあるが、backend直下で良い
  +- front      フロント関連、srcの下にコードがあるが、front直下でも良い(srcをなくす)
  +- docker     コンテナ定義関連
      +- backend バックエンドのコンテナ定義
      +- front   フロントのコンテナ定義
      +- nginx   nginxのコンテナ定義、設定ファイル 
  +- docs       ドキュメント関連

- app,public,resなど不要なフォルダは整理できたら不要になるはず
