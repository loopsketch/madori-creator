# 間取り作成ツール

スマートフォンカメラで撮影して間取り図を作成するアプリです。

## 概要

- **MVP**: 基本的な間取り作成機能を検証中
- **PWA**: インストール不要でブラウザから直接使用
- **カメラキャプチャ**: 室内環境での映像撮影・保存
- **開発環境**: Docker Compose で統一環境を構築

## 開発目標

- 室内での間取り作成を可能にする
- 基本的な壁線抽出と間取り図生成
- iPhone などのモバイル端末での利用

## 技術スタック

| 層 | 技術 |
|-----|------|
| フロントエンド | React + Vite + PWA |
| 3D レンダリング | Three.js |
| 深度推定 | ONNX Runtime + Depth Anything V2 small |
| ビルド | TypeScript + ESLint |

## 開発環境の起動

```bash
docker compose up -d
```

各サービス:

| サービス | ポート (ホスト) | 役割 |
|---------|---------------|-------|
| nginx   | 8443 (HTTPS)  | フロント/API のリバースプロキシ |
| frontend | 3000         | Vite dev server |
| backend  | 3001         | Express API + ONNX 推論 |
| db       | 3306         | MySQL 8 (将来用) |
| redis    | 6379         | (将来) セッションストア |

ブラウザで `https://localhost:8443/` (LAN なら `https://<host-ip>:8443/`) を開きます。自己署名証明書のため初回は警告が出ます。

## 撮影 → 間取り図生成の手動テスト手順

iPhone Safari (推奨) または Android Chrome で実機テストする手順です。

1. **PC で開発環境を起動**: `docker compose up -d`
2. **同一 LAN の iPhone 等で `https://<host-ip>:8443/` を開く** (PC の IP を指定)
3. 自己署名証明書の警告が出たら `詳細を表示` → `このサイトを訪問する` で許可
4. 画面中央下の **白い丸ボタンの「開始」** をタップ
5. **DeviceMotion 許可ダイアログが出るので「許可」** (iOS 13+)
6. **カメラアクセス許可ダイアログ**にも「許可」
7. ステータス表示が `撮影中` になったら、ゆっくり部屋を歩きながらスマホをかざす
   - 1 フレームのレスポンスが返るたびに次のフレームが送信される (固定間隔ではない)
   - 右上の間取り図 SVG が更新されていく
   - 左上に `frames: N / last Xms` で進捗が出る
8. 部屋を一周したら、もう一度ボタン (`停止`) をタップ
9. 最終 SVG が右上に残るので、撮影結果を確認

### 期待される挙動

- 撮影中 SVG にじわじわ壁線 (`<line>`) が増えていく
- 推論時間 (last) は CPU 性能に応じて 200ms 〜 1500ms 程度
- 通信エラー時はステータスにエラーメッセージが表示され、ループ停止
- もう一度「開始」を押すと新しいセッションで再開可能

### 既知の制約

- **絶対スケールは出ない**: 単眼カメラの原理的制約。「持ち手 150cm 仮定」で疑似スケール
- **iPhone 機種特定不可**: ブラウザでカメラ intrinsics を完全特定できないため、デフォルト値 (横画角 77°) を使用
- **同一画像の連続送信では点群が増えない**: voxel ダウンサンプルで集約されるため。実際の撮影で位置を変えると累積する
