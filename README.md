# 間取り作成ツール

スマートフォンカメラで撮影して間取り図を作成するアプリです。

## 概要

- **MVP**: 基本的な間取り作成機能を検証中
- **PWA**: インストール不要でブラウザから直接使用
- **カメラキャプチャ**: 室内環境での映像撮影・保存
- **開発環境**: Docker Compose で統一環境を構築

## 開発目標

- 室内での間取り作成を可能にする
- 基本的な壁線抽出と間取り図生成
- iPhone などのモバイル端末での利用

## 技術スタック

| 層 | 技術 |
|-----|------|
| フロントエンド | React + Vite + PWA |
| 3D レンダリング | Three.js |
| AR スキャナー | TSLib |
| ビルド | TypeScript + ESLint |
